# BotWave - Botwave WhatsApp Bot Platform

This file was generated by Claude Code as part of project initialization.

## Project Overview
BotWave is a WhatsApp bot platform that allows users to manage multiple WhatsApp sessions, configure auto-replies, polls, and more.

## Architecture
- **Frontend**: Next.js 14 with Tailwind CSS
- **Bot**: Baileys WebSocket-based WhatsApp bot
- **Database**: Supabase (PostgreSQL)
- **Auth**: Supabase Auth

## Key Directories
- `/app` - Next.js pages and API routes
- `/app/api` - REST API routes
- `/app/dashboard` - User dashboard pages
- `/app/admin` - Admin panel pages
- `/bot` - WhatsApp bot code
- `/bot/handlers` - Message and command handlers
- `/components` - React components
- `/lib` - Utilities and shared code
- `/supabase` - Database migrations

## Commands
```bash
npm run dev          # Start development server
npm run build        # Build Next.js app
npm run build:bot    # Compile bot code
npm run start:bot    # Run the bot
npm run lint         # Run ESLint
```

See `.env.example` for required environment variables.

## Bot Commands
- `#help` - Show help message
- `#ai [message]` - AI chat (requires OpenAI API key)
- `#weather [city]` - Get weather (requires OpenWeather API key)
- `#sticker` - Create sticker from image
- `#poll [question] | [options]` - Create poll
- `#play [game]` - Start a mini game
- `#leaderboard` - View top users
- `#download [url]` - Download media
